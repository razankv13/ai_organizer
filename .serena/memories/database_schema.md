# Database Schema

The app uses Drift (SQLite) for local storage with an offline-first architecture.

## Schema Location
`lib/data/database/app_database.dart`

## Tables

### Notes
Core note entity storing user notes.

Columns:
- `id` (Text, Primary Key) - UUID
- `title` (Text) - Note title
- `content` (Text, nullable) - Note body/content
- `createdAt` (DateTime) - Creation timestamp
- `updatedAt` (DateTime) - Last update timestamp
- `isPinned` (Boolean, default: false) - Pin to top
- `isArchived` (Boolean, default: false) - Archive status
- `isFavorite` (Boolean, default: false) - Favorite status
- `folderId` (Text, nullable) - Parent folder reference
- `color` (Text, nullable) - Note color code

### Tags
Reusable tags for categorizing notes.

Columns:
- `id` (Text, Primary Key) - UUID
- `name` (Text) - Tag name
- `createdAt` (DateTime) - Creation timestamp
- `color` (Text, nullable) - Tag color
- `useCount` (Int, default: 0) - Usage frequency tracking
- `description` (Text, nullable) - Tag description

### Attachments
File attachments linked to notes (images, documents, audio, etc.).

Columns:
- `id` (Text, Primary Key) - UUID
- `noteId` (Text) - Foreign key to Notes table
- `fileName` (Text) - Original file name
- `filePath` (Text) - Local file path
- `type` (Text with custom converter) - AttachmentType enum (image, document, audio, video, other)
- `fileSize` (Int, nullable) - Size in bytes
- `createdAt` (DateTime) - Creation timestamp
- `mimeType` (Text, nullable) - MIME type
- `thumbnailPath` (Text, nullable) - Path to generated thumbnail
- `metadata` (Text, nullable) - JSON metadata (dimensions, duration, etc.)

### NoteTags
Junction table for many-to-many relationship between Notes and Tags.

Columns:
- `noteId` (Text) - Foreign key to Notes
- `tagId` (Text) - Foreign key to Tags
- `createdAt` (DateTime) - When tag was applied

Primary Key: Composite (`noteId`, `tagId`)

## Custom Type Converters

### AttachmentTypeConverter
Converts `AttachmentType` enum to/from string for database storage.

Values:
- `image`
- `document`
- `audio`
- `video`
- `other`

### NullableMetadataConverter
Converts nullable Map<String, dynamic> to/from JSON string for metadata storage.

## Database Class: AppDatabase

Extends `_$AppDatabase` (generated by Drift)

Key methods:
- `getAllNotes()` - Fetch all notes
- `getNoteById(id)` - Fetch single note
- `insertNote(note)` - Create note
- `updateNote(note)` - Update note
- `deleteNote(id)` - Delete note
- `searchNotes(query)` - Full-text search
- `getAllTags()` - Fetch all tags
- `getTagById(id)` - Fetch single tag
- `insertTag(tag)` - Create tag with auto-increment useCount
- `getTagsForNote(noteId)` - Get tags for specific note
- `getAttachmentsForNote(noteId)` - Get attachments for note
- `insertAttachment(attachment)` - Add attachment
- `deleteAttachment(id)` - Remove attachment

## Schema Versioning

Current version: Check `schemaVersion` in `AppDatabase`

### Migration Strategy
When modifying schema:
1. Increment `schemaVersion` in AppDatabase class
2. Update `migration` callback to handle data migration
3. Run code generation: `flutter pub run build_runner build --delete-conflicting-outputs`
4. Test migration from previous version

### Migration Callback
The `migration` property defines how to migrate between schema versions:
```dart
migration: MigrationStrategy(
  onCreate: (m) async {
    await m.createAll();
  },
  onUpgrade: (m, from, to) async {
    // Handle version-specific migrations
  },
)
```

## Offline-First Sync Strategy

- Local Drift database is the source of truth
- Supabase used for cloud backup and multi-device sync
- Sync logic in `lib/providers/sync_provider.dart`
- Conflict resolution: "Last write wins" (currently)
- Background sync when connectivity restored

## Queries

Repository methods in `lib/data/repositories/note_repository.dart` wrap database queries and return domain models.

Common query patterns:
- Stream-based queries for reactive UI updates
- Filtering: pinned, favorite, archived notes
- Search with LIKE operator for full-text search
- Join queries for fetching notes with tags
