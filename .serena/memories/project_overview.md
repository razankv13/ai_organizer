# Project Overview

## Purpose
AI Organizer is a cross-platform mobile organizer app built with Flutter that allows users to quickly capture and intelligently organize screenshots, web content, notes, emails, and various digital assets using AI.

## Key Features
- **Unified Content Capture**: Quick add notes, screenshots, images, PDFs, links, emails
- **AI Organization**: Auto-suggest tags/folders, related notes suggestions, AI-based task/date recognition
- **Powerful Search**: Full-text search, OCR-based search, natural language queries
- **Flexible Organization**: Folder hierarchy, tagging, backlinking, task lists, favorites
- **Offline Support**: Full offline access with sync upon reconnection
- **Security**: Supabase authentication (email/password, OAuth), encryption in transit and at rest

## Target Platforms
- iOS
- Android
- Web
- macOS
- Linux
- Windows

## Backend Services
- Supabase for authentication, cloud storage, and PostgreSQL database
- Google Gemini API for AI features (image analysis, smart tagging, transcription, natural language search)
